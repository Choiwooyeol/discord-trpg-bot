# Privacy

The bot stores Discord user IDs, display names, character sheets, player actions, generated story text, and session state in the operator's SQLite database. Backups contain the same data.

Only messages inside registered TRPG game threads are sent to the configured AI provider. Lobby chatter and messages outside game threads are ignored. Operators are responsible for their own Discord server rules, data retention, backups, and deletion requests.

Do not publish database files, backups, screenshots containing player data, or server environment files.
